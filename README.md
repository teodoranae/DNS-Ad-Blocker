# DNS Ad Blocker
This is a part of my contribution to the Computer Networks project. The server_DNS_ad_blocker.py script implements a simple UDP DNS server that blocks listed ad and tracking domains from a curated list. The script binds a UDP socket on port 8053(53 requires root permissions) and receives DNS queries. If the queried name is blacklisted, the server replies with an A record pointing to 0.0.0.0 and logs the blocked domain to blocked_domains.txt. Otherwise, it resolves the domain and returns the real IP address. Then a DNS reply is constructed and sent back to the client.
